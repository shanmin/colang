# 修改记录

本记录按发布版本列出 Co（colang）语言/编译器的主要变化。
版本策略：0.* 为开发测试版，1.* 为正式版，2.* 为自举版。

## 0.2.0
- 增加裸代码、函数public、import支持；
- 增加dll/so生成；
- 根据C语言测试套件，修复若干问题。

具体开关入口与 `public` 行为见「程序入口与执行」与「函数定义」两章。

## 0.1.0
开发测试版本，已完成 C 语言编译器。
- 编译器支持 C 编译；Co 的面向对象等扩展（如 class）处于规范/规划阶段，尚未实装。

## 0.0.x
开发测试版本（历史）。功能与语法以当时测试版本为准，非发布基准。
