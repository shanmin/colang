# 简介

欢迎来到 Co程序设计 文档。

> 当前Co语言还在开发阶段，所以基本特性会在开发过程中不断的修正，最终特性请以本文档作为基准。

本文档是Co语言的基础规范说明文档，所有Co语言的语言特性均以本文档为基准。在阅读本文件前，请确认您已经具有其他语言的编程基础，也就是说本文档主要讲解Co语言特性，但不是一本编程启蒙教材。

Co语言是一个基于C语言进行扩展的新语言，Co语言尽量兼容之前C语言语法规则，除此之外包括支持部分面向对象特性。可粗略理解为 Co ≈ C + object 或 简化的C++。

Co 语言源代码文件的默认扩展名为 `.co`。

Co语言当前所有语法都以C语言为基准，所以本文档中未涉及到的内容都以现行C标准为准（推荐 C23 / C11 两个标准：C23 即 ISO/IEC 9899:2024；C11 即国标 GB/T 15272-2024《程序设计语言 C》，等同采用 ISO/IEC 9899:2011）。与C语言有冲突或扩展的内容，本文档会尽量写清。
